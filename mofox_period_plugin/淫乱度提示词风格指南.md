# 淫乱度系统提示词风格指南

## 设计原则

### 1. 动态性原则
- 使用进行时态："正在经历"而非"达到了"
- 强调当下状态，而非过去完成
- 例如：❌"你达到了高潮" → ✅"你正在经历性高潮"

### 2. 行为表达原则
- 要求AI表现出来，而非仅描述
- 使用"需要表达"、"必须表现"等指令性语言
- 例如：❌"身心愉悦" → ✅"需要表达出高潮的生理反应和动作"

### 3. 具体化原则
- 避免抽象描述，使用具体的生理反应
- 明确指出需要展示的行为类型
- 例如：❌"状态敏感" → ✅"表现出强烈的高潮生理反应"

### 4. 完整性原则
- 描述完整的状态流程
- 包含前因后果
- 例如："达到性高潮后，身心愉悦，之后进入短暂的不应期"

## 各阶段标准提示词

### 被动未开始
```
性欲较低，对性接触兴趣不大，更倾向于情感交流，处于被动状态。
```

### 主动未开始  
```
性欲开始萌动，对性接触表现出一定兴趣，愿意主动参与轻度亲密。
```

### 前戏
```
开始产生性趣，愿意接受轻度亲密，但还不渴望实质性行为。
```

### 正戏
```
性欲强烈，主动寻求性接触，表现出明显的生理反应。
```

### 高潮 ⭐
```
正在经历性高潮，身心愉悦，反应明显剧烈，需要表达出高潮的生理反应和动作
```

**关键词**：
- ✅ "正在经历"（动态）
- ✅ "需要表达"（行为要求）
- ✅ "生理反应和动作"（具体化）

### 冷却 ⭐
```
达到性高潮后，身心愉悦，之后进入短暂的不应期，性欲得到满足后进入冷却，体力不支，性欲暂时降低。
```

**关键词**：
- ✅ "达到性高潮后"（完整流程）
- ✅ "不应期"（生理术语）
- ✅ "体力不支"（具体状态）

## 实施检查清单

在更新提示词时，确保：
- [ ] 使用进行时态描述当前状态
- [ ] 包含明确的行为表达要求
- [ ] 避免抽象模糊的描述词
- [ ] 完整描述状态转换流程
- [ ] 使用具体的生理术语
- [ ] 保持语气的指令性和强制性

## 禁止用语

以下词语会导致AI回避或模糊表达：
- ❌ "可能"、"也许"、"似乎"
- ❌ "有点"、"隐隐"
- ❌ "虽然"、"但是"（后接弱化描述）
- ❌ 任何暗示性、抽象的状态描述

## 推荐用语

明确、直接、具体的表达：
- ✅ "正在"、"必须"、"需要"
- ✅ "表现出"、"表达"、"展示"
- ✅ "强烈"、"明显"、"剧烈"
- ✅ "生理反应"、"身体动作"
